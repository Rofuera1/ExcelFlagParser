# Excel → Flags

Статическая страница для замены ISO alpha-2 кодов стран на флаги в Excel. Все файлы обрабатываются локально в браузере, без сервера и отправки данных. Зависимости включены в репозиторий; сборка и Node.js для работы не нужны.

## Использование

1. Откройте сайт или `public/index.html` в современном браузере.
2. Добавьте несколько `.xlsx`, `.xls` или `.xlsm` файлов. Приложение не устанавливает лимит количества; доступный объём ограничен памятью браузера.
3. Для каждой книги выберите лист и столбец с кодами. Если первая заполненная строка диапазона — заголовок, оставьте флажок пропуска включённым.
4. Выберите «Только флаг» или «Флаг и код» и нажмите «Преобразовать файлы».
5. Скачайте XLSX по отдельности или одним ZIP-архивом. Для PDF нажмите «Сохранить PDF» у нужного файла и выберите «Сохранить как PDF» в окне печати браузера.

PDF содержит выбранный лист, включая все его столбцы и столбцы с картинками за пределами диапазона данных. Флаги остаются Unicode-эмодзи в текстовых ячейках. Для XLSX/XLSM переносятся жирное и курсивное начертание, размер и семейство шрифта, подчёркивание, зачёркивание, цвета, заливка, границы, выравнивание, форматированные фрагменты текста, объединения ячеек и встроенные DrawingML-картинки. Изображения размещаются в соответствующих ячейках; исходные плавающие координаты адаптируются к новой ширине таблицы. Пустые строки внутри таблицы сохраняются как визуальные разделители; их исходная высота учитывается вместе с масштабом печати (при отсутствии заданной высоты исходным считается значение 15 пунктов). Строки только с картинками также остаются. Пустой хвост после последнего текста, картинки или связанного объединения ячеек не печатается. Шрифты, отсутствующие на устройстве, заменяются браузером. Диаграммы, фигуры, условное форматирование, внешние картинки и формулы IMAGE не рендерятся в PDF. Неподдерживаемый браузером формат встроенной картинки вызывает ошибку с предложением заменить её на PNG/JPEG, а не незаметную потерю изображения.

Перед печатью загружаются локальный шрифт флагов и все картинки. Сохранение и встраивание шрифтов выполняет браузер; рекомендуется Chrome или Edge. По умолчанию используется A4 в вертикальной ориентации. Ширина столбцов автоматически подбирается по содержимому, таблица занимает ширину страницы, длинный текст переносится. Дата и URL браузера скрываются нулевыми верхним и нижним полями страницы в Chromium; отступы таблицы повторяются на каждой странице. Если вручную изменить поля или использовать другой браузер, может понадобиться снять флажок «Колонтитулы» в дополнительных настройках печати. Исходная печатная вёрстка Excel не воспроизводится. Заголовки таблицы печатаются только в исходном месте, без повторения на следующих страницах. Для компактного вывода размеры шрифтов, высоты строк и картинок масштабируются до 77% от исходных; начертание и пропорции размеров сохраняются. Отступы внутри ячеек уменьшены. Для защиты браузера от зависания область PDF ограничена 250 000 ячеек включая внутренние пустые строки.

Коды обрезаются по краям и приводятся к верхнему регистру: ` de ` → `🇩🇪` или `🇩🇪 DE`. `AIN` → `🏳️` или `🏳️ AIN`. Пустые значения остаются пустыми. Неизвестные коды и формулы в выбранном столбце сохраняются с предупреждением. Используется список 249 ISO 3166-1 alpha-2 кодов; нестандартные коды вроде `UK` и `XK` не заменяются.

Обрабатывается выбранный столбец выбранного листа. При повторном преобразовании используется исходная книга. Для XLSX/XLSM заменяются только значения ячеек в исходном ZIP-пакете: стили, изображения, макросы, другие листы и остальные части книги сохраняются без пересборки. XLSM остаётся XLSM. Пустые строки в Excel сохраняются, чтобы не нарушить формулы и привязки объектов; в PDF они также остаются как визуальные разделители. Для старого `.xls` используется прежний экспорт в `.xlsx` с предупреждением об ограничениях сохранения оформления и картинок. Чтобы сохранить их, сначала пересохраните исходный `.xls` в `.xlsx` средствами Excel. Отображение флагов в Excel зависит от шрифтов и ОС. Загружайте исходную книгу: картинки и оформление, утраченные при предыдущем преобразовании, восстановить из результата нельзя.

## GitHub Pages

В репозитории `Rofuera1/ExcelFlagParser`:

1. Отправьте файлы проекта в ветку `main`.
2. В **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**.
3. Запустите **Actions → Deploy GitHub Pages → Run workflow** (или отправьте новый коммит в `main`).

Workflow публикует только каталог `public`. Ожидаемый адрес после успешного развёртывания: https://rofuera1.github.io/ExcelFlagParser/

Конфигурация основана на [документации GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

## Проверка

Откройте `tests/index.html` в браузере. Автоматические проверки используют настоящие Excel-книги в памяти: оба формата, AIN, пустые и неизвестные значения, формулы, повторное чтение результата, несколько листов и ZIP. Статус отображается на странице.

Дополнительно проверяются побайтовая сохранность неизменяемых частей XLSX, индексы стилей, шрифты, цвета, rich text, DrawingML-картинки за границей диапазона данных и сохранение пустых строк-разделителей и строк только с картинками.

`tests/ui.html` дополнительно проверяет сценарий интерфейса: загрузку нескольких файлов, изоляцию ошибок, выбор листа и столбца, скачивание XLSX и ZIP, повторное преобразование и мобильную ширину. Для этой страницы нужен локальный HTTP-сервер либо запуск Chrome с `--allow-file-access-from-files`, поскольку тест управляет приложением внутри iframe. Для самого приложения этот флаг не нужен.

## Зависимости

- [SheetJS CE 0.20.3](https://docs.sheetjs.com/docs/getting-started/installation/standalone/) — чтение и запись Excel, Apache-2.0. `public/vendor/xlsx.full.min.js`.
- [JSZip 3.10.1](https://github.com/Stuk/jszip) — ZIP, MIT. `public/vendor/jszip.min.js`.
- [Twemoji Country Flags](https://github.com/talkjs/country-flag-emoji-polyfill) 0.1.8 — локальный шрифт флагов для интерфейса и печати PDF, подмножество Twemoji Mozilla. Mozilla Foundation: Apache-2.0; графика Twemoji от Twitter и участников: CC BY 4.0. Изменение оригинального шрифта: оставлены флаги стран. В файлы Excel шрифт не встраивается.

Лицензии находятся в `public/vendor/`. Обновление библиотек — заменой файлов из официальных источников с повторным запуском проверок.
