# Excel → Flags

Статическая страница для замены ISO alpha-2 кодов стран на флаги в Excel. Все файлы обрабатываются локально в браузере, без сервера и отправки данных. Зависимости включены в репозиторий; сборка и Node.js для работы не нужны.

## Использование

1. Откройте сайт или `public/index.html` в современном браузере.
2. Добавьте несколько `.xlsx`, `.xls` или `.xlsm` файлов. Приложение не устанавливает лимит количества; доступный объём ограничен памятью браузера.
3. Для каждой книги выберите лист и столбец с кодами. Если первая заполненная строка диапазона — заголовок, оставьте флажок пропуска включённым.
4. Выберите «Только флаг» или «Флаг и код» и нажмите «Преобразовать файлы».
5. Скачайте результаты по отдельности или одним ZIP-архивом.

Коды обрезаются по краям и приводятся к верхнему регистру: ` de ` → `🇩🇪` или `🇩🇪 DE`. `AIN` → `🏳️` или `🏳️ AIN`. Пустые значения остаются пустыми. Неизвестные коды и формулы в выбранном столбце сохраняются с предупреждением. Используется список 249 ISO 3166-1 alpha-2 кодов; нестандартные коды вроде `UK` и `XK` не заменяются.

Обрабатывается выбранный столбец выбранного листа; остальные листы и значения включаются в результат. При повторном преобразовании используется исходная книга. Результат всегда `.xlsx`. SheetJS CE не гарантирует сохранение сложного оформления, диаграмм, изображений, внешних связей и других расширенных возможностей Excel; макросы не сохраняются. Используйте копию исходной книги. Отображение флагов зависит от шрифтов и ОС, в том числе в Excel.

## GitHub Pages

В репозитории `Rofuera1/ExcelFlagParser`:

1. Отправьте файлы проекта в ветку `main`.
2. В **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**.
3. Запустите **Actions → Deploy GitHub Pages → Run workflow** (или отправьте новый коммит в `main`).

Workflow публикует только каталог `public`. Ожидаемый адрес после успешного развёртывания: https://rofuera1.github.io/ExcelFlagParser/

Конфигурация основана на [документации GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

## Проверка

Откройте `tests/index.html` в браузере. Автоматические проверки используют настоящие Excel-книги в памяти: оба формата, AIN, пустые и неизвестные значения, формулы, повторное чтение результата, несколько листов и ZIP. Статус отображается на странице.

`tests/ui.html` дополнительно проверяет сценарий интерфейса: загрузку нескольких файлов, изоляцию ошибок, выбор листа и столбца, скачивание XLSX и ZIP, повторное преобразование и мобильную ширину. Для этой страницы нужен локальный HTTP-сервер либо запуск Chrome с `--allow-file-access-from-files`, поскольку тест управляет приложением внутри iframe. Для самого приложения этот флаг не нужен.

## Зависимости

- [SheetJS CE 0.20.3](https://docs.sheetjs.com/docs/getting-started/installation/standalone/) — чтение и запись Excel, Apache-2.0. `public/vendor/xlsx.full.min.js`.
- [JSZip 3.10.1](https://github.com/Stuk/jszip) — ZIP, MIT. `public/vendor/jszip.min.js`.
- [Twemoji Country Flags](https://github.com/talkjs/country-flag-emoji-polyfill) 0.1.8 — локальный шрифт флагов для интерфейса на Windows, подмножество Twemoji Mozilla. Mozilla Foundation: Apache-2.0; графика Twemoji от Twitter и участников: CC BY 4.0. Изменение оригинального шрифта: оставлены флаги стран. В файлы Excel шрифт не встраивается.

Лицензии находятся в `public/vendor/`. Обновление библиотек — заменой файлов из официальных источников с повторным запуском проверок.
